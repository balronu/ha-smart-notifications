# Branding provenance

The raster icon artwork was generated for this project with OpenAI Image Generation on 2026-10-23 from an original prompt requesting a geometric bell, connected-device dots and sound-wave arcs. It contains no Home Assistant, Google or Music Assistant logo. The repository also contains a deterministic SVG mark used for scalable local branding. The project owner authorized bundling these assets in this repository.

Home Assistant 2026.3+ local integration branding is stored under `custom_components/smart_notifications/brand/`. GitHub Social Preview remains a repository setting; `assets/github-social-preview.png` is a ready-to-upload 1280×640 source and is not an automatic repository setting.
