# Branding provenance

The owner-supplied design overview is the visual reference for the bundled artwork: blue bell, turquoise sound waves, orange clapper and three connected device nodes. The deployed raster set is generated deterministically by `tools/build_branding.py` at the required dimensions; it is not a cropped or upscaled copy of the overview. It contains no Home Assistant, Google or Music Assistant logo. The project owner authorized bundling these assets in this repository.

Home Assistant 2026.3+ local integration branding is stored under `custom_components/smart_notifications/brand/`. GitHub Social Preview remains a repository setting; `assets/github-social-preview.png` is a ready-to-upload 1280×640 source and is not an automatic repository setting. The current Brands PR policy does not accept new custom-component additions; no official CDN availability is claimed.
