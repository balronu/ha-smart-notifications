# v0.1.0-beta.11

## Deutsch

Beta.11 behebt einen mobilen Lovelace-Fehler im Ereigniseditor. Ursache war, dass der `hass`-Setter bei Home-Assistant-State-Updates eine Aktualisierung startete, die nach dem API-Aufruf den gesamten Shadow-DOM per `innerHTML` ersetzte. Während iOS Safari/WKWebView ein natives `select`-Menü geöffnet hielt, konnte dieses DOM-Replacement das Menü unmittelbar schließen.

Die Karte markiert nun Fokus- und Pointer-Interaktionen und stellt ausstehende Rebuilds zurück, bis die Interaktion beendet ist. Der geöffnete Editor wird während Hintergrundaktualisierungen nicht neu aufgebaut. Damit bleiben Nachrichtentyp, Priorität, Aktivierungsstatus, Parameter, Textfelder, Textareas und Ausgabegeräte bedienbar; die bestehende Beta.10-Nachrichten- und Preview-Pipeline bleibt unverändert.

Validiert wurden 49 isolierte Python/HA-Tests, Ruff, Compileall, JSON- und JavaScript-Syntax sowie ein Chromium-Fixture-Test mit Auswahl, Fokus/Pointer-Interaktion und simuliertem HA-Update. Ein echter iOS-/WebKit-Test war in der Entwicklungsumgebung nicht verfügbar; der Praxistest auf iPhone bleibt offen.

## English

Beta.11 fixes a mobile Lovelace event-editor bug. The cause was the `hass` setter starting a refresh on Home Assistant state updates; after the API call, the refresh replaced the complete shadow DOM via `innerHTML`. While iOS Safari/WKWebView had a native `select` menu open, that DOM replacement could close the menu immediately.

The card now tracks focus and pointer interactions and defers pending rebuilds until the interaction ends. An open editor is not rebuilt during background updates. Message type, priority, enabled state, parameters, text fields, textareas and output-device selection therefore remain usable; the existing Beta.10 message and preview pipeline is unchanged.

Validation covered 49 isolated Python/HA tests, Ruff, compileall, JSON and JavaScript syntax, plus a Chromium fixture covering selection, focus/pointer interaction and a simulated HA update. A real iOS/WebKit test was not available in the development environment; the practical iPhone test remains open.
