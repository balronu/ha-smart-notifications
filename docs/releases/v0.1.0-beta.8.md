# v0.1.0-beta.8

## Deutsch

Beta.8 erweitert die bestehende Smart-Notifications-Lovelace-Karte um eine verständliche Discovery-Oberfläche. Ergebnisse können gesucht, gefiltert, nach sicherer Gruppierungsregel zusammengefasst und in einer Detailansicht geprüft werden. Automation-/Skriptnamen werden aus dokumentierten YAML-Metadaten gelesen; technische IDs bleiben als Fallback sichtbar.

Der Übernahmeassistent erlaubt die Bearbeitung von Ereignis-ID, Name, Nachricht, Priorität und Ausgabegeräten. Übernommene Ereignisse werden immer deaktiviert gespeichert. Automationen und Skripte werden weder geändert noch migriert.

Die Erkennung liest weiterhin ausschließlich `automations.yaml` und `scripts.yaml`. UI-/Storage-Automationen werden nicht über private Home-Assistant-APIs ausgelesen. Dynamische Templates werden als Quelltext und zur manuellen Prüfung angezeigt; sie werden nicht mit erfundenen Werten ausgewertet.

## English

Beta.8 extends the existing Smart Notifications Lovelace card with a readable discovery interface. Results can be searched, filtered, grouped only when the documented grouping signals match, and reviewed in a detail view. Automation/script names come from documented YAML metadata; technical IDs remain visible as an explicit fallback.

The adoption assistant allows editing the event ID, name, message, priority, and output devices. Adopted events are always stored disabled. Automations and scripts are never changed or migrated.

Discovery still reads only `automations.yaml` and `scripts.yaml`. UI/Storage automations are not read through private Home Assistant APIs. Dynamic templates are shown as source text for manual review and are never rendered with invented values.
