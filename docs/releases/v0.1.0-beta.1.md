# v0.1.0-beta.1 – Beta release

## Deutsch

Diese erste Beta bringt eine native Home-Assistant-Config-/Options-Konfiguration, einen gemeinsamen Ereigniskatalog, zentrale Nachrichtentexte, TTS über `tts.speak`, Push über Notify-Entitäten und best-effort-physische Duplikaterkennung. Die aufrufende Automation benötigt nur `smart_notifications.send` mit `reason`.

**Kompatibilität:** Home Assistant 2026.10.2, Python 3.14.2+. Die Beta muss in HACS ausdrücklich als Pre-Release ausgewählt werden. Nach der Installation ist ein Home-Assistant-Neustart erforderlich.

**Einschränkungen:** Keine Produktiv-VM-Validierung; keine Kamera-/Livevideo-Aktionen, Töne, kritischen iOS-Alarme, Music-Assistant-Announcements, Ruhezeiten oder persistenten Warteschlangen. Physische Identitäten müssen in der UI geprüft werden.

## English

This first beta provides native Home Assistant Config/Options flows, a shared event catalog, shared message texts, TTS through `tts.speak`, push through notify entities, and best-effort physical-device duplicate suppression. Calling automations only need `smart_notifications.send` with `reason`.

**Compatibility:** Home Assistant 2026.10.2, Python 3.14.2+. Pre-releases must be explicitly selected in HACS. A Home Assistant restart is required after installation.

**Limitations:** No productive-VM validation; camera/live-video actions, tones, critical iOS alerts, Music Assistant announcements, quiet hours and persistent queues are not included. Physical identity matches must be reviewed in the UI.
