# v0.1.0-beta.2 – Beta release

## Deutsch

Beta.2 behebt den Setup-Fehler unter Home Assistant 2026.10, der durch die
veraltete Static-Path-API verursacht wurde. Das Options-Flow-Menü verwendet
jetzt die aktuelle Übersetzungsstruktur und zeigt keine leeren Einträge mehr.
Config-Flow-Felder, Geräteklassen und TTS-Engines werden verständlich
angezeigt. Bestehende Beta.1-Optionen werden additiv übernommen.

Die Lovelace-Ressource wird innerhalb des Lifecycles idempotent registriert.
Die mitgelieferte Karte bleibt bewusst bei manueller einmaliger Ressourcen-
Registrierung. Es werden weiterhin keine produktiven TTS- oder Push-Tests
ausgeführt. Live-Validierung auf VM 104 ist nicht Bestandteil dieses Releases.

## English

Beta.2 fixes the setup failure on Home Assistant 2026.10 caused by the removed
static-path API. The Options Flow now uses the current translation structure and
no longer displays empty menu entries. Config Flow fields, device classes and
TTS engines have clear labels. Existing Beta.1 options are migrated additively.

The Lovelace resource registration is idempotent within the integration
lifecycle. The bundled card still requires one manual resource registration by
design. No production TTS or push tests are performed. Live validation on VM
104 is not part of this release.
