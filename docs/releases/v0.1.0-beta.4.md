# v0.1.0-beta.4 – Beta release

## Deutsch

Beta.4 repariert die Bedienbarkeit des Options Flows:

- Die sieben Hauptbereiche sind beschriftet und öffnen native Untermenüs.
- Jedes Untermenü bietet „Zurück zum Hauptmenü“.
- Ein Formular wird nur nach explizitem Absenden gespeichert; Schließen verwirft ungespeicherte Eingaben.
- Geräte werden mit Anzeigename, Bereich, Integration und Ausgabeart dargestellt.
- `device_id`, `physical_group` und Prioritätswerte sind verständlich übersetzt.
- Leere Gerätelisten zeigen eine klare Anleitung statt leerer Auswahlfelder.
- Die statische Config-Flow-Beschreibung enthält weiterhin keinen `{device_count}`-Platzhalter.

Home Assistant 2026.10 oder neuer wird vorausgesetzt. Die produktive VM 104 wurde für diesen Release nicht geändert und es wurden keine Testausgaben gesendet.

## English

Beta.4 improves the Options Flow usability:

- The seven main areas are labeled and open native submenus.
- Every submenu provides “Back to main menu”.
- A form is persisted only after explicit submission; closing it discards unsaved input.
- Devices are shown with name, area, integration and output channel.
- `device_id`, `physical_group` and priority values have user-facing translations.
- Empty device lists show clear guidance instead of empty selectors.
- The static Config Flow description still contains no `{device_count}` placeholder.

Home Assistant 2026.10 or newer is required. Production VM 104 was not changed for this release and no test output was sent.
