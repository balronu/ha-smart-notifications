# v0.1.0-beta.9

## Deutsch

Beta.9 ist ein gezielter Hotfix für die Lovelace-Verfügbarkeit. Beta.8 registrierte den statischen JavaScript-Pfad, lud das Modul aber nicht über die unterstützte Home-Assistant-Frontend-API. Dadurch wurde `window.customCards` im Karteneditor nicht ausgeführt. Beta.9 verwendet `frontend.add_extra_js_url` mit einer versionierten URL und registriert weiterhin den statischen Pfad als Modulquelle.

Der Ereignis-Bearbeiten-Flow zeigt gespeicherte Anzeigenamen, Nachrichtentexte, Status, Priorität, Beschreibung und Duplikatschutz nach der Ereignisauswahl wieder korrekt an. Automationsebene-Trigger und Bedingungen werden an Discovery-Kandidaten weitergereicht; zusammengehörige Ausgaben werden gruppiert, unterschiedliche Quellen/Trigger getrennt.

Die Karte bleibt unter `custom:smart-notifications-card` verfügbar. Nach HACS-Upgrade ist einmalig ein harter Browser-Refresh empfohlen. VM 104, Automationen, Skripte und produktive Ausgaben wurden nicht verändert.

## English

Beta.9 is a targeted Lovelace availability hotfix. Beta.8 exposed the static JavaScript path but did not load the module through Home Assistant's supported frontend API. Therefore `window.customCards` was not executed for the card picker. Beta.9 uses `frontend.add_extra_js_url` with a versioned URL and keeps the static path as the module source.

The event edit flow now restores saved display names, message text, enabled state, priority, description, and deduplication settings after event selection. Automation-level triggers and conditions are carried into discovery candidates; related outputs are grouped and different sources/triggers remain separate.

The card remains available as `custom:smart-notifications-card`. A one-time hard browser refresh is recommended after a HACS upgrade. VM 104, automations, scripts, and productive outputs were not changed.
