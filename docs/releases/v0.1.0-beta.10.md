# v0.1.0-beta.10

## Deutsch

Beta.10 führt ein gemeinsames Nachrichtenmodell für manuelle Ereignisse, Discovery-Übernahmen und `smart_notifications.send` ein.

- Statischer Text, Home-Assistant-Templates, Laufzeitparameter und kombinierte Nachrichten
- `variables` mit Text-, Zahlen- und Boolean-Parametern, Pflichtfeldern und Standardwerten
- Zentrale, sichere Render-Pipeline über Home Assistants Template-Engine
- Lesende Nachrichtenvorschau ohne TTS, Push, Automation oder Skriptausführung
- Lovelace-Ereigniseditor mit Nachrichtentyp, Template, Parametern und Geräteauswahl
- Discovery kennzeichnet Templates, Variablen, ungeklärte Herkunft und fehlende Geräte
- Ereignis-ID-Vorschläge basieren nicht mehr auf Template-Variablen
- Übernommene Ereignisse bleiben deaktiviert; Automationen und Skripte bleiben unverändert

Bestehende Beta.9-Ereignisse bleiben kompatibel. Nicht konfigurierten oder unklar zugeordneten Geräten werden nicht automatisch als Ziele verwendet.

## English

Beta.10 introduces one shared message model for manually created events, discovery adoption and `smart_notifications.send`.

- Static text, Home Assistant templates, runtime parameters and combined messages
- `variables` with text, number and boolean parameters, required fields and defaults
- One safe rendering pipeline using Home Assistant's supported template engine
- Read-only message preview without TTS, push, automation or script execution
- Lovelace event editor with message type, template, parameters and device assignment
- Discovery labels templates, variables, uncertain origin and missing devices
- Event ID suggestions are no longer derived from template variables
- Adopted events remain disabled; automations and scripts remain unchanged

Existing Beta.9 events remain compatible. Unconfigured or ambiguous targets are never selected silently.

## Upgrade notes

After a HACS upgrade, reload Home Assistant using the normal process and hard-refresh the browser once so the versioned card module URL is loaded. No manual template migration is performed. Review dynamic events before enabling them.
