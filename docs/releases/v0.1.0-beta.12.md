# v0.1.0-beta.12

## Deutsch

Beta.12 behebt einen Regressionseffekt aus Beta.11: Bei einer mobilen Touch-Sequenz konnte ein HA-State-Update zwischen `pointerup` und dem synthetischen `click` einen zurückgestellten DOM-Rebuild ausführen. Dadurch wurde der angeklickte „Bearbeiten“-Button ersetzt, bevor sein `click`-Handler lief.

Der Interaktionsschutz priorisiert nun den `click`, bricht den verzögerten Release-Timer ab und gibt ausstehende Rebuilds erst nach dem Klickfenster frei. Die Beta.11-Sicherheit für native Auswahlmenüs bleibt erhalten. Der Ablauf Bearbeiten → Nachrichtentyp → HA-Update → Auswahl erhalten → Abbrechen/erneutes Öffnen/Speichern ist als Browser-Regression abgedeckt.

Validiert wurden 49 isolierte Python/HA-Tests, Ruff, Compileall, JSON- und JavaScript-Syntax sowie ein Chromium-Touch-/Pointer-Fixture-Test. Ein echter iOS-/WebKit-Test war nicht verfügbar; der iPhone-Praxistest bleibt offen.

## English

Beta.12 fixes a regression introduced by Beta.11: during a mobile touch sequence, a Home Assistant state update between `pointerup` and the synthesized `click` could apply a deferred DOM rebuild. That replaced the tapped “Edit” button before its `click` handler ran.

The interaction guard now gives `click` priority, cancels the delayed release timer, and applies pending rebuilds only after the click window. The Beta.11 protection for native selection menus remains in place. The edit → message type → HA update → selection retained → cancel/reopen/save flow is covered by a browser regression fixture.

Validation covered 49 isolated Python/HA tests, Ruff, compileall, JSON and JavaScript syntax, plus a Chromium touch/pointer fixture. A real iOS/WebKit test was not available; the practical iPhone test remains open.
